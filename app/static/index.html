        Comment ça marche

        1. Importe un cours : il est converti en texte Markdown modifiable (le fichier d'origine reste consultable).
        2. Retravaille-le dans l'éditeur, ou sélectionne un passage et utilise les Outils texte (corriger, reformuler, simplifier…).
        3. Ouvre le panneau ✨ IA pour générer une fiche, des exercices, un QCM, des flashcards… ou discuter avec ton cours.
        4. Révise chaque jour les flashcards : la répétition espacée te les représente au bon moment.
        🌐 Ce document est en anglais. Les termes techniques garderont leur nom anglais entre parenthèses, ex. « noyau (kernel) ».
        📷 page(s) scannée(s) n'ont pas de texte.
        🌐 Traduit de l'anglais par l'IA ·
